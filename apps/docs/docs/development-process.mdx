# Development Process

## Simulation agent

:::info[Info]

This **Actor** exist only during demonstration process and can be used for testing as well, but **not** in the **Production** state

:::

A Simulationm agent is program which simulates users behaviour. Main purpose is to demonstrate proper functionalitie of the site. If there is a need it can be used as a part of the testing process too.
