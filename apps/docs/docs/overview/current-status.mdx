# Current Status

This page describes the checked-in implementation. Production deployment and
release acceptance are separate from the presence of working source code.

## Implementation summary

| Area            | Current state                                                                                                                                       |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Web             | Cluster map at `/`, email/password login and registration, session guards, responsive place details, and administrator approvals at `/admin/users`. |
| API             | Public database health check; authenticated cluster list, layout, occupancy, configuration validation, and SSE endpoints.                           |
| Authentication  | Better Auth sessions, administrator approval, current-role checks, logout, and rate limiting for login, registration, and approval.                 |
| Database        | Drizzle auth and Hive schemas, three checked-in migrations, PostgreSQL Compose service, and a local demo seed.                                      |
| Live updates    | Shared per-cluster database polling every 30 seconds while subscribed, SSE deltas, and frontend recovery snapshots.                                 |
| Shared packages | Auth and cluster DTOs in `@repo/types`, application errors in `@repo/errors`; `@repo/validators` still contains example validation.                 |
| Tests           | API unit and integration suites and frontend Vitest suites; optional PostgreSQL auth integration test.                                              |
| Deployment      | Dockerfiles for API, web, DB, and docs; full-stack Compose; Nginx web/API proxy and docs hosting.                                                   |
| Documentation   | Docusaurus site with separate development and build commands.                                                                                       |

See [Local Development](../getting-started/local-development) to run the app and
[API Reference](../reference/api) for the implemented contracts.

## Remaining work

- Hive OAuth, two-factor authentication, and a profile page.
- Connect configuration-validation results to map warnings; the frontend currently
  supplies an empty warnings array.
- Define an age-based stale threshold and measurable performance/accessibility
  acceptance criteria. Current stale behavior responds to failures, not data age.
- Validate production occupancy integration and database privileges. The current
  client is shared by occupancy reads and authentication writes.
- Implement the simulation agent; the demo seed supplies static fixtures only.
- Implement GitHub Actions, secrets-manager integration, WAF/TLS hardening,
  environment-specific deployments, and backup/rollback procedures.
- Verify the [Transcendence requirements](./transcendence-requirements) against
  delivered behavior; the points table is a target, not an acceptance result.
