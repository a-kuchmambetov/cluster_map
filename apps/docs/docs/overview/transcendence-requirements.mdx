## Implementation evidence and gaps

- React/Express, Drizzle, SSE, GitHub OAuth, and Docusaurus are present in the
  repository. Browser compatibility and design-system acceptance still need
  verification against the module criteria.
- CI checks pull requests, while branch deployment workflows independently
  publish images and trigger Coolify. They do not wait for CI, poll deployment
  health, or perform automatic rollback. See [CI/CD Implementation](../development-and-testing/CI-CD-implementation).
- Container entrypoints use Infisical. HashiCorp Vault and WAF/ModSecurity
  configuration are not checked in, so the listed security target is not
  established by the current implementation.
- TOTP enrollment, verification, trusted-device login, and disabling are exposed.
  Backup codes are displayed during setup, but there is no backup-code recovery
  route. See [Authentication endpoints](../reference/api#authentication-endpoints).
