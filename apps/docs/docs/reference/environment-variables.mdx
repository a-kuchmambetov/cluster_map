# Environment Variables

API and DB configuration load the root `.env` via their workspace-relative path.
Vite uses the root as its environment directory. Existing process variables take
precedence over dotenv values.

| Variable             | Default / requirement                     | Consumer                                                                                      |
| -------------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------- |
| `NODE_ENV`           | Unset locally                             | Production masks API internal errors, writes JSON request logs, and blocks demo seeding.      |
| `API_PORT`           | `5000`; template sets `5001`              | API listener, Vite proxy target, and Compose host API port (container stays on 5000).         |
| `WEB_ORIGIN`         | `http://localhost:5173`                   | Credentialed CORS and trusted browser origin for authentication.                              |
| `PG_USER`            | `app`                                     | DB connection user; Compose PostgreSQL user.                                                  |
| `PG_DB`              | `app`                                     | DB name.                                                                                      |
| `PG_PASSWORD`        | `app`                                     | DB password.                                                                                  |
| `PG_HOST`            | `localhost`                               | DB host; Compose overrides API host to `db`.                                                  |
| `PG_PORT`            | `5432`                                    | Local DB port / Compose published DB port; API container uses 5432.                           |
| `BETTER_AUTH_SECRET` | Required for auth; at least 32 characters | Better Auth secret. Template leaves it empty.                                                 |
| `BETTER_AUTH_URL`    | Required valid URL for auth               | Better Auth base URL. Template uses `http://localhost:5000`; align with your API URL locally. |
| `VITE_API_URL`       | Empty (same origin)                       | Build-time frontend API origin, without `/api`; Vite reads it from the root environment.      |
| `DOCKER_WEB_ORIGIN`  | `http://localhost:8080`                   | Compose API's `WEB_ORIGIN` and `BETTER_AUTH_URL`.                                             |
| `WEB_PORT`           | `8080`                                    | Compose web host port; changing this does not automatically change `DOCKER_WEB_ORIGIN`.       |
| `DOCS_PORT`          | `8081`                                    | Compose docs host port.                                                                       |
| `AUTH_DB_TEST`       | Unset                                     | Set to `1` to run the PostgreSQL auth integration test against a migrated disposable DB.      |

`PG_PASSWORD_FILE` and a `DATABASE_URL` environment override are not consumed by
the current connection code. Secret-file delivery is future work, not an
implemented alternative to `PG_PASSWORD`.

There are no environment settings for the layout file path, SSE poll interval,
frontend recovery interval, or stale-data age threshold. Current polling and
recovery use 30-second constants; stream access checks use 20 seconds.

See [Configuration](../getting-started/configuration) for a consistent local
example and [Deployment](../operations/deployment) for Compose behavior.
